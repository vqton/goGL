# Ledger Module — Web UI / UX Design

> Tailwind v4 (rebuild via `npm run build:css`), Go `html/templates` in
> `web/templates/` (layout `base.html`, pages define `title`/`content` blocks).
> All ledger pages render server-side; print via `@media print` styles.

## 1. Information architecture

```
Ledger (Kế toán tổng hợp)  [sidebar entry, visible by role]
├── Sổ kế toán
│   ├── Sổ Nhật ký chung      /ledger/books/general-journal
│   ├── Sổ Cái                /ledger/books/ledger
│   ├── Sổ chi tiết           /ledger/books/detail
│   └── Bảng cân đối số phát sinh  /ledger/books/trial-balance
├── Phiếu kế toán
│   ├── Danh sách             /ledger/entries
│   ├── Tạo / sửa             /ledger/entries/new  /ledger/entries/:id
│   └── Đảo bút toán          (from entry detail)
├── Sơ đồ tài khoản           /ledger/accounts
├── Kỳ kế toán
│   ├── Danh sách kỳ          /ledger/periods
│   ├── Mở / khoá sổ          (from period detail)
│   └── Kết chuyển cuối kỳ    /ledger/periods/:id/close
├── Bút toán định kỳ          /ledger/templates
└── Số dư đầu kỳ              /ledger/opening-balances
```

## 4. UX rules

- Server-rendered pages only (no JS framework), consistent with web module.
- Amounts formatted VND `1,234,567,890` with `.` thousands separator; no decimals.
- Every mutation surfaces an inline result banner (success VN copy / 422 rule list).
- Khoá sổ state visible on every entry/period screen (avoid R4 surprises).
- Print buttons use `/books/…?format=print` returning the print layout.
- Dashboard (web home) shows: period status, pending posting-errors count,
  cash vs GL 111 reconciliation delta.
