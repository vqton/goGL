# Web UI / UX — Cashier (Thủ quỹ) Module

Stack: Gin `html/templates` (`web/templates/`, layout `base.html`, blocks `title`/`content`), Tailwind v4 (`web/css/input.css` → generated `web/static/css/app.css`, gitignored). VN-language UI. Pages register on the `/api/v1` SPA or server-rendered under `/web` root (per `web/handler.go` pattern — decide SPA vs server-render in roadmap; initial goGL is server-rendered templates).

## 1. Information architecture

```
Phân hệ Quỹ & Thủ quỹ (/cash)
├── Bảng điều khiển quỹ   (fund dashboard: balances, today's tx)
├── Phiếu thu / Phiếu chi (voucher list + create/edit)
├── Đề nghị thu, chi      (cashier queue: approved unposted → Ghi sổ)
├── Sổ quỹ tiền mặt       (S07-DN view + print)
├── Sổ chi tiết quỹ       (S07a-DN view + print) [accountant]
├── Khóa sổ / Kiểm kê     (daily close + cash count)
├── Đối chiếu cuối tháng  (reconciliation + biên bản)
└── In ấn biểu mẫu        (01-TT, 02-TT, S07-DN, S07a-DN, biên bản)
```

## 7. Templates (print)

Templates rendered server-side (Go `html/template`) → printable HTML. Statutory fields per TT99:

| Template | Columns / fields |
|---|---|
| Phiếu thu (01-TT) | Số quyển, số phiếu, ngày, Nợ/Có, họ tên người nộp, diễn giải, số tiền (số + chữ), tỷ giá (FX), kèm theo, chữ ký (người lập, KTT, thủ quỹ, người nộp) |
| Phiếu chi (02-TT) | same shape, "người nhận tiền", "lý do chi", "kèm theo chứng từ gốc" |
| S07-DN | columns A B C D E 1 2 3 G; tồn running; signature row (người ghi sổ, KTT, đại diện+dấu) |
| S07a-DN | accountant parallel; column G signature |
| Biên bản kiểm kê quỹ | ngày giờ, thành phần tham gia, số liệu sổ, số liệu kiểm kê, chênh lệch + xử lý, chữ ký |

## 8. UX notes

- Numbers formatted VN: thousands separators `.`, decimal `,`; amount-in-words helper.
- State badges: draft (gray), approved (blue), posted (green), reconciled (dark), voided (red strikethrough).
- Role-based menu: cashier sees queue + sổ quỹ + khóa sổ; accountant sees voucher forms + sổ chi tiết + đối chiếu.
- Keyboard-first: Ctrl+A select all in queue (MISA parity).
- All destructive actions require typed reason + confirm modal.
- Responsive: list/queue on mobile; print forms desktop-only.

## 9. Accessibility & i18n

- Labels associate inputs; contrast AA; focus visible.
- VN default locale; amount-in-words localized.
- Error messages in VN, actionable (e.g. "Tồn quỹ không đủ — kiểm tra phiếu thu trước").
