# Master Data Module (Hệ thống danh mục dữ liệu chính) — UI/UX Specification

> Web UI in the existing Go `html/templates` stack (layout `base.html`,
> Tailwind v4 via `web/css/input.css`). VN-first language; EN labels as
> secondary. All money/date formatting follows the cash module helpers
> (int64 VND minor units; `dd/MM/yyyy`; số tiền bằng chữ where relevant).

## 1. Design system (reuse cashier/ledger patterns)

- Layout: left sidebar with phân hệ → **Danh mục** (Đối tượng, Vật tư-hàng hóa,
  Sơ đồ tài khoản, TSCĐ, Nhân viên, Thuế, Ngân hàng, Kho, Đơn vị tính, …),
  main content card, top bar with user + regime badge (`TT 99/2025`).
- Components: data table (sort/filter/paginate), search box (code/name/MST),
  status pill (Đang sử dụng / Ngừng sử dụng), toasts for 201/409/422,
  modal confirm for deactivate/merge/delete, dialog with dry-run report.
- Empty state: "Chưa có dữ liệu — Nhập từ Excel hoặc Thêm mới".
- Accessibility: keyboard-nav forms, labels, focus states, WCAG contrast.
- Regime badge must be visible when chart-of-accounts variant ≠ TT 99 default.

## 3. Key UX rules

1. **Mã tự động mặc định**, mã người dùng vẫn được phép nếu khác biệt (Q1).
2. **Bất kỳ 409/422 nào đều có lý do VN + EN** và hành động gợi ý (xem công nợ,
   mở template mới, gộp thay vì sửa mã).
3. **Excel là đường dẫn bình đẳng**: mọi danh mục đều có import/export; dry-run
   bắt buộc trước commit.
4. **Ngừng sử dụng ≠ xóa**: luôn có nhánh khôi phục (activate) và lịch sử.
5. **Regime & thời hạn hiệu lực** hiển thị nổi bật cho tài khoản/thuế suất
   (tránh hạch toán vào chế độ cũ).
6. **Keyboard speed**: nhập mã + Enter để chuyển focus, F2 tạo mới nhanh từ
   chứng từ (nhảy nhanh — UC journey 9.2).

## 4. Templates & localization

- Base: `web/templates/base.html` (extend existing). New:
  `md/catalogs.html`, `md/customer_form.html`, `md/accounts.html`,
  `md/import.html`, `md/merge.html`, `md/quality.html`,
  `md/_table.html` (shared partial).
- Strings: VN primary, EN secondary (keyed i18n map, mirroring cash module).
- Money: `45.500.000 ₫` (VND, int64 minor); dates `dd/MM/yyyy`.
- Excel templates under `web/static/md/templates/{kind}.xlsx` (versioned `v2`).
