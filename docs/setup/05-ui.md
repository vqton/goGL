# Setup Module (Khởi tạo hệ thống / Cấu hình doanh nghiệp) — UI/UX Specification

> Web UI in the existing Go `html/templates` stack (layout `base.html`,
> Tailwind v4 via `web/css/input.css`). VN-first; EN labels secondary. Money:
> `int64` VND minor units, `45.500.000 ₫`; dates `dd/MM/yyyy`; periods `MM/yyyy`.

## 1. Design system (reuse masterdata/ledger patterns)

- Layout: left sidebar with **Khởi tạo hệ thống** entry; wizard pages for the
  first run, a Status dashboard afterwards; top bar shows regime badge
  (`TT 99/2025` / `TT 133/2016`) once set.
- Wizard: stepper (1. Thông tin doanh nghiệp → 2. Chế độ & kỳ → 3. Sơ đồ TK →
  4. Số dư đầu kỳ → 5. Hoàn tất), progress indicator, per-step Save & Continue.
- Components: form card with inline VN+EN validation, stepper, step-checklist
  table, balance table (Nợ/Có columns with running Σ), balance-check banner
  (green/red), modal confirm for lock/reopen/activate, dry-run import report.
- Empty state: "Chưa có dữ liệu — Bắt đầu khởi tạo".
- Accessibility: keyboard nav, labeled fields, focus states, WCAG contrast.

## 3. Key UX rules

1. **Wizard không phá vỡ nửa chừng**: crash → bước đã xong hiển thị ✓,
   tiếp tục từ bước dở dang (idempotent resume — UC-S11).
2. **Mọi 409/422 có lý do VN + EN** và hành động gợi ý (xem đối ứng, tải
   template, bổ sung đối tượng).
3. **Cân đối hiển thị sống**: bảng số dư cập nhật Σ Nợ/Σ Có sau mỗi lần thêm,
   banner đỏ/xanh ngay lập tức (R9).
4. **Đối tượng bắt buộc có nhắc**: với TK 131/331/152/211-214, ô đối tượng
   highlight nếu bỏ trống (R10).
5. **Khóa là điểm không quay lại** (trừ Reopen có lý do) — nút Khóa kèm modal
   cảnh báo rõ ràng.
6. **Regime badge hiển thị trên mọi màn hình** sau khi set (tránh hạch toán
   theo chế độ cũ).
7. **CSV là đường dẫn bình đẳng** với nhập tay: template tải sẵn, dry-run
   bắt buộc trước commit.
