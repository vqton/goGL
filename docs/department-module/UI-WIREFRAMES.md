## 2. Component Specifications

### 2.1 Department Tree Component

| Property | Type | Description |
|----------|------|-------------|
| `data` | `Department[]` | Flat list of departments |
| `selectedCode` | `string` | Currently selected department code |
| `onSelect` | `(code: string) => void` | Selection callback |
| `onTransfer` | `(code: string, newParent: string) => void` | Transfer callback |
| `expandable` | `boolean` | Enable expand/collapsible nodes |
| `draggable` | `boolean` | Enable drag-and-drop reorganization |
| `showEmployeeCount` | `boolean` | Show employee count badge |
| `filterStatus` | `'all' \| 'active' \| 'inactive'` | Filter by status |

### 2.2 Department Form Component

| Property | Type | Description |
|----------|------|-------------|
| `mode` | `'create' \| 'edit'` | Form mode |
| `initialData` | `Department \| null` | Initial form data (edit mode) |
| `parentOptions` | `Department[]` | Parent department options |
| `managerOptions` | `Employee[]` | Manager employee options |
| `costCenterOptions` | `CostCenter[]` | Cost center options |
| `onSubmit` | `(data: DepartmentInput) => void` | Form submission callback |
| `onCancel` | `() => void` | Cancel callback |
| `validation` | `ValidationRules` | Form validation rules |

### 2.3 Cost Report Component

| Property | Type | Description |
|----------|------|-------------|
| `departmentCode` | `string` | Department code (empty for all) |
| `fiscalYear` | `number` | Fiscal year |
| `period` | `'month' \| 'quarter' \| 'year'` | Reporting period |
| `data` | `CostReportData` | Budget vs actual data |
| `onExport` | `(format: 'pdf' \| 'excel') => void` | Export callback |

## 4. Responsive Design

### 4.1 Desktop (1024px+)
- Full tree view with drag-and-drop
- Side-by-side form layout
- Detailed cost reports with charts

### 4.2 Tablet (768px - 1023px)
- Collapsible tree view
- Stacked form layout
- Simplified cost reports

### 4.3 Mobile (< 768px)
- List view only (no tree)
- Full-screen form
- Basic cost table (no charts)
