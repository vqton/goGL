# Admin/Configuration Layer (Quản trị hệ thống) — UI/UX Specification

> Web UI in the existing Go `html/templates` stack (layout `base.html`,
> Tailwind v4 via `web/css/input.css`), following the `websetup` pattern.
> VN-first; EN labels secondary. Dates `dd/MM/yyyy HH:mm`; tables striped;
> destructive actions double-confirmed.

## 1. Design system (reuse websetup/ledger patterns)

- Layout: left sidebar with **Quản trị hệ thống** section (Đăng nhập →
  Người dùng, Vai trò, Cài đặt, Sao lưu, Nhật ký, Thông tin hệ thống). Top
  bar shows current user + role + last-backup badge.
- Components: login card, users table (status pill), role-policy editor
  (select obj/act rows), settings form (typed inputs + validation),
  backup schedule form + artifact table, restore wizard (2 steps + approval),
  audit viewer (filter + CSV export).
- Empty state: "Chưa có bản sao lưu — lịch sao lưu chưa chạy".
- Accessibility: keyboard nav, labeled fields, WCAG contrast, focus states.

## 3. Routing

- `/login` — pre-auth page (not behind middleware).
- `/system` — admin dashboard (tabs) → `/system/users`, `/system/roles`,
  `/system/settings`, `/system/backup`, `/system/backup/restore`,
  `/system/audit`, `/system/info`. Guarded by session + role; renderer reads
  principal from the session resolver (not the header) once auth lands.

## 4. Accessibility & format

- All money `45.500.000 ₫` (VND minor), dates `dd/MM/yyyy`, datetime
  `dd/MM/yyyy HH:mm`, VN labels primary.
- Contrast AA, focus rings, aria-labels on icon-only buttons, form errors
  inline VN+EN.
